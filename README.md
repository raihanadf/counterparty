# counterparty

**see who's on the other side of the trade.**

live order flow for crypto perps, the same data as [aggr.trade](https://aggr.trade), in a native mac app.

[**download for mac**](https://github.com/raihanadf/counterparty/releases/latest/download/Counterparty.dmg)

<sub>free · macos 14 or later · swift, no dependencies</sub>

</div>

## features

- aggr's chart, averaged across every perp
- real order book per exchange, with its tape
- any coin, ⌘P to search
- tabs that keep streaming in the background
- (?) mode explains every number
- trackpad gestures, tradingview style
- 9 themes, or import your own
- works behind dns blocks

## build

```sh
./bundle.sh && open Counterparty.app
```
